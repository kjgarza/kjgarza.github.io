# Scoring Matrix for Job Analysis

## Multi-Dimensional Score (100%)

| Dimension | Weight | Scoring Guide |
|-----------|--------|---------------|
| **Domain alignment** | 30% | Scholarly infra / open science = 100, AI/ML platform = 90, devtools/research = 80, knowledge management = 70, general SaaS = 30 |
| **Seniority fit** | 20% | Director/Head = 100, Principal/Staff/Lead = 90, Manager = 85, Senior = 50, Mid = 10 |
| **Skill stack overlap** | 20% | (matched skills / required skills) × 100. Key skills: Python, FastAPI, LLMs, RAG, LangChain, pgvector, Docker, Kubernetes, AWS, design systems |
| **Work arrangement** | 15% | Remote Europe = 100, Berlin-based = 100, Remote global = 80, Hybrid Berlin = 70, Other EU city = 50, US-only = 0 |
| **Mission/culture** | 15% | Open source + research-driven = 100, mission-oriented = 80, commercial but ethical = 50, pure enterprise = 20 |

## Recommendation Thresholds

| Score | Recommendation |
|-------|----------------|
| 80%+  | GO — strong match, apply confidently |
| 60-79%| STRETCH — good match with gaps, apply with honest framing |
| <60%  | PASS — significant misalignment, not worth applying |
